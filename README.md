Este proyecto se trata de un juego completamente modular, con el objetivo de poder crear lo que tu quieras dentro de el, si quieres jugar 
un simulador de construcción espacial, solo tendrías que tocar algunas opciones y ya lo podrías jugar, o si quieres hacer algo más avanzado,
como recrear sistemas completos de juego dentro del juego, solo tendrías que instalar algunos mods creados por la comunidad para poder jugar 
a tu propia versión del juego que quieras dentro de este mismo, el objetivo del juego, es poder replicar los sistemas de juegos con mundos
destructibles como Minecraft, o otros parecidos pero, sumándole el nivel de detalle de un mundo 3D, con ello poder crear o hacer lo que quieras
en el juego, con una ambientación 3d detallada, modular y propia.
